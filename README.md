# Spark UI Architecture Practice

## Project Overview
This project focuses on practicing Apache Spark data processing and understanding Spark UI execution details using Databricks.

The project uses customer and order datasets to explore data loading, transformations, execution plans, and performance monitoring.

## Technologies Used
- Python
- Apache Spark (PySpark)
- Databricks
- Git and GitHub
- Jupyter Notebook

## Project Structure
```text
Spark_UI_Architecture_Practice/
├── data/
│   ├── customers.csv
│   └── orders.csv
├── Spark_UI_Architecture_Practice.ipynb
├── spark_ui_practice.py
├── README.md
└── .gitignore
```

## Current Implementation
- Loaded customer and order CSV datasets using Spark.
- Configured CSV reading options, including headers and schema inference.
- Displayed the loaded DataFrames for inspection.
- Practiced data cleaning, aggregations, and Delta Lake table operations in Databricks.

## Learning Objectives
- Understand Spark execution and the Spark UI.
- Practice DataFrame transformations and actions.
- Explore query execution and performance optimization.
- Learn Git version control and GitHub project management.

## How to Use
1. Clone this repository.
2. Open the notebook in a compatible Jupyter environment or Databricks.
3. Configure the dataset paths for your environment.
4. Run the notebook cells in order.

## Note
The dataset paths used in Databricks may need to be updated when running the project locally.
